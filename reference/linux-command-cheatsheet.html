Linux 基础命令速查

先确认位置，再操作目标。命令不是咒语：通常由“命令 + 选项 + 参数”组成。

位置与目录

目的命令提示
当前用户whoami本机默认应为 ubuntu
当前位置pwd输出绝对路径
列出内容ls -lah-a 含隐藏项，-h 易读大小
进入目录cd 路径cd ~ 回家，cd .. 上一级
创建目录mkdir -p a/b连同缺失的父目录一起创建

文件操作

目的命令提示
创建空文件touch note.txt已有文件只更新时间
复制cp 原文件 新文件目录复制需 cp -r
移动/改名mv 原路径 新路径同一条命令完成两种操作
查看短文本cat 文件大文件改用 less
查找文本grep -n "词" 文件-n 显示行号
查找文件find . -name "*.py". 表示当前目录

路径心智模型

写法含义本机示例
/Linux 根目录/usr/bin/python3
~当前用户家目录/home/ubuntu
.当前目录python3 ./main.py
..上一级目录cd ..
/mnt/cWindows C 盘/mnt/c/Users/12924/Desktop
删除前的三秒检查：先运行 pwd，再运行 ls 目标，最后才考虑 rm。不要复制不理解的 sudo 或 rm -rf 命令。
