Lesson 0001 · 约 8 分钟

知道自己在哪，才能安全地动手

这一课只练一个能力：读懂路径，并在 Ubuntu 目录与 Windows 文件之间安全移动。

完成标准：你能不看答案回到家目录、显示隐藏文件，并解释常见路径符号。

1. 打开终端，先问三个问题

STEP 01

我是谁？我在哪？这里有什么？

whoami
pwd
ls

本机预期看到用户 ubuntu，家目录是 /home/ubuntu。终端只处理你输入的命令，不会自动替你猜目标路径。

2. 在安全练习区操作

STEP 02

创建目录并进入

mkdir -p ~/linux-practice/docs
cd ~/linux-practice
pwd

~ 代表 /home/ubuntu；因此最后一行应输出 /home/ubuntu/linux-practice。

STEP 03

创建、复制、改名

touch docs/first-note.txt
cp docs/first-note.txt docs/note-copy.txt
mv docs/note-copy.txt docs/renamed.txt
ls -la docs

你应看到 first-note.txt 和 renamed.txt。这里没有删除操作，失败时可直接重来。

3. 绝对路径与相对路径

STEP 04

用 . 和 .. 在目录之间移动

cd ~/linux-practice/docs
pwd
cd ..
pwd
cd ./docs
pwd

.. 表示上一级，. 表示当前目录。以 / 开头的是绝对路径；其他写法通常是相对路径。

4. 从 Linux 查看 Windows 文件

STEP 05

Windows C 盘在 Linux 中位于 /mnt/c

cd /mnt/c/Users/12924/Desktop
pwd
ls
cd ~

最后一条命令会让你回到 Linux 家目录。这里只查看 Windows 桌面，不修改其中的文件。

5. 闭卷自测

先在终端作答，再展开答案。不要边看边抄。

任务 A：不管当前在哪，一条命令回到家目录
cd ~
任务 B：列出当前目录，包含隐藏项并显示易读大小
ls -lah
任务 C：进入练习区的 docs，再用一个命令回到上一级
cd ~/linux-practice/docs
cd ..
